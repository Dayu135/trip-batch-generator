# 行程批量生成器（飞书多维表格自定义插件）

给「出差&接待计划」表中已有的出差单、接待单批量补录行程明细，数据写入「【子表】出差&接待行程明细」。

## 功能

- 选择填写人（软隔离，只列该人名下单据）
- 下拉选择已有出差/接待单，显示客户，待补行程的单据优先
- 逐段填写行程：日期（自动带出）、开始/结束时间、具体地点、行程安排、主要会见人员、交流内容
- 提交后批量写入行程子表，自动挂到所选单据下

## 技术栈

- 构建工具：Vite 5
- SDK：`@lark-base-open/js-sdk`（作为 npm 依赖本地打包，**不使用任何外部 CDN**，满足飞书安全审核要求）
- 打包方式：vite-plugin-singlefile，产物为单个 `dist/index.html`（约 1MB，SDK 已内联）
- 路径：相对路径（`base: './'`），符合飞书插件规范

## 项目结构

```
.
├─ index.html          # 源码入口（HTML + CSS + 业务逻辑）
├─ package.json        # 依赖与构建脚本，含 "output": "dist"
├─ vite.config.js      # 相对路径 + 单文件打包配置
├─ dist/
│  └─ index.html       # 构建产物（上架时必传，飞书部署的就是这个文件）
├─ .gitignore          # 忽略 node_modules，但保留 dist
└─ README.md
```

## 本地构建

```bash
npm install
npm run build
```

产物输出到 `dist/index.html`。

## 上架到飞书

飞书"添加自定义插件 → 插件代码 Github 地址"要求仓库包含**标准项目结构 + dist 构建产物**，飞书会拉取代码、审核并部署。因此：

1. 把本仓库**全部文件**（含 `dist/` 目录，但**不含 `node_modules/`**）上传到 GitHub
2. 在飞书开发者中心/应用页提交 GitHub 仓库地址（如 `https://github.com/Dayu135/trip-batch-generator`）
3. 发布范围按需选择（要让其他人使用需选"当前企业可见"或"公开"）
4. 等待飞书安全审核与部署

> 注意：`dist/index.html` 必须提交到仓库，否则飞书拉取后无法部署，会报"上架失败"。

## 使用

1. 插件上架通过后，在多维表格应用页添加该插件组件
2. 首次打开点右上角「字段映射」，确认主表/子表及字段对应正确
3. 选填写人 → 选出差/接待单 → 逐段加行程 → 提交
